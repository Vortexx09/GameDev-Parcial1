# GameDev-Parcial1
# Práctica de Unity: Mapa de Normales e Iluminación

Este repositorio contiene la solución al ejercicio práctico de Unity sobre la aplicación de **Normal Maps**, materiales y fuentes de luz puntuales.

---

## Descripción del Proyecto

El objetivo principal de esta práctica es demostrar cómo un mapa de normales modifica el cálculo de iluminación píxel por píxel para generar la ilusión de relieve e interactuar con una fuente de luz puntual (*Point Light*) sobre un objeto tridimensional (*Sphere*) de color rojo.

---

## Herramientas Utilizadas

* **Unity Engine**: Motor de desarrollo de la escena y aplicación de materiales.
* **GIMP**: Software de edición con el que se generó el mapa de normales a partir de un texto.
* **Git & GitHub**: Control de versiones y alojamiento del repositorio.

---

## Pasos Realizados / Historial de Commits

El proyecto fue construido y registrado a través de **4 commits obligatorios**:

1. `creando esfera`: Creación y posicionamiento del objeto 3D (*Sphere*) en la escena.
2. `texturizando esfera`: Importación del Mapa de Normales generado en GIMP (configurado como *Normal Map*) y asignación dentro del canal correspondiente del Material.
3. `agregando luz`: Creación y ajuste de una luz puntual (*Point Light*) para resaltar el relieve y la profundidad del Normal Map.
4. `coloreando esfera de rojo`: Configuración del color base (*Albedo / Base Map*) del material a color rojo.
